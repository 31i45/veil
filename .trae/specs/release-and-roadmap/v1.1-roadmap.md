# Veil v1.1 Roadmap

目标窗口：**tag v1.1.0 前 2–3 周**（建议 2026-12 上半月）。
状态：v1.0 门禁六条件全过，以下条目为 v1.0 明确降级或未覆盖项。

---

## 永恒设计原则重申
**Veil 是单机单用户纯离线 Markdown 编辑器。永不引入多用户协作、网络同步、云端存储。**
本 roadmap 中所有条目均为单机单用户场景。

---

## 优先级分区

| 优先级 | 含义 | 阻塞 tag v1.1 |
|---|---|---|
| **P0** | v1.0 回归或数据安全缺口 | ✅ |
| **P1** | 用户明显感知的功能补全 | ⚠️ 不通过立项 v1.2 |
| **P2** | 功能完善 / 体验提升 | ❌ 可降级到 v1.2 |
| **P3** | 硬件依赖 / 平台差异 | ❌ 有设备再测 |

## v1.1 门禁条件

1. **批次 A** 中至少 1 条有真机证据（A5 Mica 可视即可）
2. **批次 C** 全部通过（H2 菜单导航 + C7 图片细测，P1 不通过立项 v1.2）
3. **批次 D** 全部脚本化通过
4. P0 回归为 0
5. `cargo test --workspace` + `cargo clippy -- -D warnings` 零告警
6. release exe 大小 ≤ 6 MiB（v1.0 为 5.58 MiB）
