# 3e 真机走查清单与预期效果

> 适用产物：`target\release\veil.exe`（单文件，5.54 MiB，含 VERSIONINFO 与图标，构建命令 `cargo build --release -p veil`）
> 目的：完成阶段 3 的最后一批**人工验收项**（P4 专家清单、IME 复核、3b 打印、3c 交互、3d 分发外观、盲测前置）
> 记录方式：每条勾 □通过 / □不通过；不通过时填「实际现象 + 复现步骤 + 严重度（阻断/高/中/低）」

## 0. 准备

- [ ] 用 release 构建，不用 `cargo run`（debug 构建带控制台窗口，不是发布形态）
- [ ] 备份 `%APPDATA%\Veil\`（`config.toml` / `session.txt` / `recovery.dat`）后，先清空一次做冷环境
- [ ] 准备素材：①1 万字中文长文 ②含表格/图片/公式的混合文档 ③10 万字纯文本 ④一个 200 字连续输入用的空白文件
- [ ] 准备对照软件（可选）：Typora / VS Code 同机同文档，用于手感对比

冷启动计时（5 次取中位）：

```powershell
1..5 | ForEach-Object {
  $t0 = Get-Date
  $p = Start-Process .\target\release\veil.exe -PassThru
  while ($p.MainWindowHandle -eq 0) { Start-Sleep -Milliseconds 5 }
  [math]::Round(((Get-Date) - $t0).TotalMilliseconds)
  Stop-Process -Id $p.Id -Force
}
```

## I. 盲测（前置条件，非本轮自动验收）

- 对象：3–5 名目标用户（中文长文/技术写作），未看过产品
- 任务：①打开给定 1 万字文档，改一个错别字并保存 ②新建文档写 200 字并插入一张图 ③导出 HTML

- 通过线：3/5 人能在无提示下完成三项任务，且至少 2 人能说出「快/不丢字/源码可信」之一
