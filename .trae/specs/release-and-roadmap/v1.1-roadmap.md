# Veil v1.1 Roadmap

目标窗口：**tag v1.1.0 前 2–3 周**（建议 2026-12 上半月）。
状态：C1 / B2 / B3 / 链接视觉已在 converge 批次交付；A5-part 仅剩外部真机证据。

## 事实校准（2026-11-06）

1. **代码块语法高亮已在 v1.0 实现**（`crates/veil-ui/src/view/highlight.rs`，16 语言、自研逐行状态机、无 syntect，已接线 `layout.rs` 518–523 行并有单测），本版不列入任何缺口。
2. **表格行列增删已接线交付**（右键 6 项经 `Editor::replace_table_block` 整块替换落盘，一次 undo）；底层 helper 仍在 `paint.rs`（`table_delete_row` / `table_insert_column` / `table_delete_column`）。
3. **体积预算余量偏紧**：release exe 实测 5,914,112 B（≈5.64 MiB），门禁上限 6 MiB，余量约 0.36 MiB。

---

## 永恒设计原则重申
**Veil 是单机单用户纯离线 Markdown 编辑器。永不引入多用户协作、网络同步、云端存储。**
本 roadmap 中所有条目均为单机单用户场景。

---

## 优先级分区

| 优先级 | 含义 | 阻塞 tag v1.1 |
|---|---|---|
| **P0** | v1.0 回归或数据安全缺口 | ✅ |
| **P1** | 用户明显感知的功能补全 | ⚠️ 不通过立项 v1.2 |
| **P2** | 功能完善 / 体验提升 | ❌ 可降级到 v1.2 |
| **P3** | 硬件依赖 / 平台差异 | ❌ 有设备再测 |

## v1.1 门禁条件

1. **必做块代码侧全部交付**（C1 / B2 / B3 / 链接视觉已交付；A5-part 代码侧完成，仅剩外部证据）
2. **Win10 不崩必须有一次虚拟机或真机记录**（替代原"批次 A 至少 1 条真机证据"）——外部证据待补，不阻塞代码合入，阻塞 tag
3. `tools/walkthrough.ps1` 脚本化用例全绿
4. P0 回归为 0
5. `cargo test --workspace` + `cargo clippy --workspace --all-targets -- -D warnings` 零告警
6. release exe ≤ 6 MiB。当前实测 5,914,112 B（≈5.64 MiB），余量约 0.36 MiB；新增依赖前必须做体积评估
