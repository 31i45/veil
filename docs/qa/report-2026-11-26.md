## 裁决记录

- **EDGE-014（相对路径上跳）**：契约更正为「按文档目录解析，允许 `../`；命中真实位图则内嵌 data URI，缺失/0 字节/非位图删除 `src`」。理由：Veil 为本地编辑器，文档引用兄弟目录资产是常见合法用法；导出仅读取本地文件且只内嵌位图 MIME，不产生外发通道。断言改为同时要求 `src="data:image/png` 与不得保留 `../assets/a.png`，不再是“删掉即通过”的弱断言。
- **WYSIWYG 零高度不变量**：新增「可见块高度必须 > 0」断言（折叠 `<details>` 内部块例外，由 `details_hidden` 标注）。该断言首轮即抓出 4 个用例并把它们归因为折叠 details 的预期 0 高，确认后放行；图片真实位图几何另由 `veil-ui` 的 `app_tests/media.rs` 位图越界测试覆盖。
- **图片紧邻表格**：`CASE-TBL-012/013` 的块序列、块间不重叠、导出 `<img>`+`<table>` 并存均通过；产品层实测几何由 `media.rs` 的位图底缘不越后续块断言兜底。

## 降级与边界说明

- 断言口径（D4）：`html_contains`/`html_not_contains` 比较前对正文与期望片段做开始标签属性归一（h1–h6、details、summary、th、td、table、thead、tbody、tr、ul、ol、li、p、pre、code、figure、blockquote、mark），使 `<h1 id=…>` ≡ `<h1>`、`<details open>` ≡ `<details>`、`<th style=…>` ≡ `<th>`；属性类原文片段（`class=`、`id=`、`alt=` 等）仍按原文严格命中，纯文本片段不归一。
- `html_not_contains` 仅在 `<body>…</body>` 范围内检查，head 内的 `<style>`/`<title>` 不计为正文泄漏。
- 金样比较保持原文严格，不受上述归一影响。
- `no_overlap`：PDF 版面未暴露块级包围盒，改用 headless UI 的块几何（`top`/`height`，容差 0）判断相邻块不相交；该断言记在 PDF 表面。
- PDF 关键文本：PDF 字节流中文本为字形 CID，无法直接检索 Unicode；关键文本取自同一次 `layout_document` 的 `DrawOp::Text`（与 `render_pages` 同一版面数据）。
- PRINT：仅断言打印分页模型（页数/断点单调/首断点为 0）；物理打印需要 GDI 设备上下文，全部记为 NOT RUN。
- HTML 中的 Mermaid：harness 不启动 QuickJS 离线引擎，`mermaids=None` 按产品既定策略降级为源码围栏，故 `<svg` 断言记 NOT RUN（不伪造通过）。
- 金样首次缺失时自动写入（引导），之后普通运行全文比对。
