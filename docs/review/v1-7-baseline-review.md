## 3. 三层审查

### L-A 契约（先写，半天，一页）

审查开始前落定，否则审美判断没有基准：

- 功能边界：v1.7 已交付能力，一条一句。
- 非目标：与第 7 节及 README 保持一致。
- 交互原则：焦点归属、取消语义、快捷键不冲突、浮层关闭后的状态恢复。
- 视觉原则：间距层级、字号层级、状态色、动效时长与缓动、空态与错误态表达。

### L-B 核心旅程（10 条，真实 exe 走一遍）

每条只判「观察点是否成立」，不展开原子矩阵。失败即立项，通过即记录。

1. 启动与打开：双击关联、CLI 传参、拖入文件；标题栏、状态栏、最近文件正确。
2. 编辑闭环：输入、选区、撤销/重做、查找替换、行内格式、自动配对。
3. 保存与恢复：`Ctrl+S`、外部修改提示、崩溃恢复、版本历史留档与恢复。
4. 图片：粘贴、拖入、远程图片加载与全局阻止、失败降级 alt、题注与边框。
5. 表格与代码：Tab 跳格、行列增删、对齐、列宽拖动、代码块语言标签与复制。
6. 导出：HTML 与 PDF；保存对话框、目录页、页脚页码、书签、失败回退。
7. 主题与视图：浅/深/跟随系统、缩放 50%–300%、`F11`、大纲、专注与打字机。
8. 窗口：新建窗口、双窗口编辑、退出三选一、关闭后恢复。
9. 异常路径：非法路径、无权限、磁盘错误、损坏配置与恢复数据。
10. 输入法：中文组合输入，组合中切窗口、开面板、进全屏。

### L-C 设计系统横切（8 维，逐维扫全界面）

横切比逐屏更容易发现「局部好看、整体不一致」：

1. 间距与对齐：同一层级数值是否统一。
2. 字号与层级：标题、正文、辅助文字是否有明确梯度。
3. 状态完整性：hover / pressed / disabled / focus 是否都存在且可区分。
4. 焦点与键盘：Tab 顺序、Esc 语义、焦点可见性、关闭后恢复。
5. 空态与错误态：每种空数据与失败是否有可理解表达。
6. 动效：时长、缓动、跟随系统「显示动画」、无残留定时器。
7. 深浅色：同一元素在两套主题下的对比度与层级一致。
8. 缩放与 DPI：命中区、描边、图片、浮层位置不漂移。

## 4. 判定与记录

- 结论用六态：通过 / 缺陷 / 未覆盖 / 不适用 / 未提供 / 受阻；未执行不得写通过。
- 证据分级沿用 E1（真机截图或测量）、E2（自动化测试）、E3（静态代码）；E3 不能单独证明视觉或交互通过。
- 缺陷记严重度（S0–S3）、复现步骤、影响范围、根因位置、修复后回归项。
- 能力缺口（未提供）与缺陷分开记，不合并计数。

## 5. 风险面清单（无状态，仅提示重点）

1. 输入法组合中切换上下文是否吞字、重复或残留 preedit。
2. 浮层关闭后焦点、光标、选区、滚动是否恢复。
3. 多窗口与多实例下 recovery、自动保存、退出是否互毁。
4. 缩放与 DPI 变化后命中区、描边、浮层是否漂移。
5. 外部修改、外部删除、文件被占用时的提示与数据保全。
6. 写入失败是否假报成功；原子写与临时文件残留。
7. 网络策略：重定向、凭据头、超时、大小上限、异常 MIME。
8. 屏幕、打印、PDF、HTML 四个通道语义是否一致。
9. 深浅色与高对比下的可读性。
10. 中文排版：中英混排间距、行首行尾禁则、标点悬挂。
11. 超长文档、超长单行、深嵌套、大量图片下的降级。
12. 系统集成：文件关联、图标、任务栏、打印驱动缺失。

## 6. 不可测清单（标注即止，不反复尝试）

- 第二、第三输入法与日韩 IME（本机仅微软拼音）。
- 多显示器、负坐标、断开显示器后的窗口恢复。
- 系统 DPI 逐档切换（125% / 100%）。
- 真实外网目标、注册表写入、物理打印机与打印预览。
- 屏幕阅读器与高对比模式的完整无障碍通道。

以上只标注「不可测 + 已完成的替代验证」，不判通过，也不计入缺陷。

## 7. 非目标（与 README 一致）

- wgpu / GPU 渲染（ADR-011 触发式）。
- 协作编辑 / CRDT（永久排除，单用户单文档）。
- 拼写检查、插件系统、移动端与 PWA。
- 表格合并与拆分单元格。
- Mermaid 渲染本身（保留代码块与后端中立接口）。
- 独立富文本文档模型（正文始终是 Markdown）。
- 后台网络：同步、更新检查、遥测；远程图片按需请求可全局关闭。
- 竞品对齐类放弃项：正则查找、整词匹配、`Ctrl+Shift+K` 删行、独立 H5/H6 字号。

2. 每条旅程一轮；发现缺陷先修，再回归受影响旅程，不重跑全量。
3. 环境不可测项写入第 6 节后不再尝试。
4. 功能新想法只进 backlog，不进入本轮范围。
5. 执行阶段的代码改动另立任务并单独提交，不与本文档变更混合。
