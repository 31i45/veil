# 31 天，我把一个 Markdown 编辑器写到了 3.0

2026 年 10 月 24 日深夜，我写下了 Veil 的第一份设计文档。

起因很具体：Typedown 是我在 Windows 上最喜欢的 Markdown 编辑器，没有之一，但它每次启动要几十秒到几分钟。一个写笔记的工具，打开比泡一杯咖啡还慢，这件事不该存在。于是我决定自己造一个。

今天，2026 年 11 月 23 日，Veil 发布 v3.0.1。

## 这 31 天

- 10 月 24 日：写下设计文档与前三份 ADR，确定「纯 Rust、无 WebView、单文件 exe」
- 11 月 6 日：v1.0.0 发布
- 11 月 21 日：v3.0.0 发布，Mermaid 改为进程内离线渲染，图表源码不再离开本机
- 11 月 23 日：v3.0.1，构建管道与仓库健康度收口

31 个自然日里，有 30 天留下了开发记录，293 次提交。这不是一个周末项目，是把每一天都填满的结果。

## 它现在是什么

一句话：一个安静、瞬时、永不背叛你源码的写作表面。

- **一个 exe，13.4 MiB**。没有 Electron，没有 Chromium，没有 WebView，没有运行时依赖，双击即开。
- **冷启动 145–190 ms**，10 万字文档下敲键到落字 p95 约 2.6 ms，常驻内存 40.76 MB。
- **完整的中文写作循环**：增量解析、语义选区、表格编辑、公式、图片、脚注、锚点、大纲、查找替换（含正则与捕获组）、版本历史、多窗口。
- **原生矢量 PDF 与自包含 HTML 导出**，多级书签、CJK 字体子集化，所有输出可搜索、可复制。
- **离线 Mermaid**：QuickJS + 完整 mermaid.js 在进程内渲染，不联一次网。
- **零遥测、零后台网络、零更新检查**。MIT 许可，你的文档只属于你。

数字大概是这样：

| 指标 | 结果 |
|---|---|
| 提交 / 版本 | 293 次 / 从 v1.0.0 到 v3.0.1 |
| 代码规模 | 4 个 crate，137 个 Rust 文件，约 9.8 万行 |
| 测试 | 1313 通过，clippy 零警告 |
| CommonMark 0.31.2 | 652 个用例，A/C/D 三个维度全过 |
| 无编辑往返 | 逐字节 100% 一致 |
| 单文件体积 | 13.40 MiB（门禁 14 MiB） |

同机对比一个熟悉的 Electron 编辑器：内存 40.76 MB 对 365 MB，安装体积 13.4 MiB 对 489 MB。

## 几句实话

Veil 目前只支持 Windows x64（Windows 10 / 11），界面只有中文；正式验收环境为 Windows 11 23H2+。

发布包用的是自签名开发证书，**会在你的机器上显示未知发布者，SmartScreen 可能拦截**。这是已知状态，不是事故：生产证书需要实名与付费，我还没有推进。下载后请按 README 校验 SHA-256，确认文件完整。

渲染层面也有边界。PDF 的中文换行是简化版禁则处理，和编辑区不会逐像素一致；部分 Mermaid 图表在深色主题下的对比度仍是已知且已记录的限制。这些我不打算用「即将支持」糊过去，它们就是当前的边界。

## 来试试，也来拆台

唯一的官方下载地址：https://github.com/31i45/veil/releases

用上一天，如果它让你少等了几次启动、少关了几个浏览器标签，那就是它存在的意义。

如果发现 bug、觉得某个交互别扭、或者有更好的实现思路，欢迎提 issue；愿意动手的话，PR 同样欢迎。Veil 不打算做缝合怪，也不为了对齐竞品而加功能，但任何让「写作」这件事更安静、更快的改动，都值得讨论。

31 天可以造出一个能日用的编辑器。接下来的时间，我想把它磨到没有存在感。
