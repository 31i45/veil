# N9 代码块中文字形真机验收

目的：代码块（fenced / 缩进 / 块级 HTML / FrontMatter / 行内代码）中的汉字必须与正文汉字同族（Microsoft YaHei UI），
字形实心、无空心/描边；Latin 仍为 Consolas 等等宽族。

## 1. 正文基线（对照）

正文汉字基线：中文渲染正常，字形实心，笔画清晰可辨。正文 Latin baseline: The quick brown fox 0123456789.

## 2. Fenced 代码块（无语言）

```
// 中文注释：这一行必须实心，与上方正文同族
fn main() {
    // 变量名仍是等宽 Latin
    let 用户名 = "张三";
    println!("你好，世界");
}
```

## 3. Fenced 代码块（rust 高亮）

```rust
// 中文注释：初始化配置，读取用户偏好
```
