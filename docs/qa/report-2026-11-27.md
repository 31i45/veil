## 降级与边界说明

- 断言口径（D4）：`html_contains`/`html_not_contains` 比较前对正文与期望片段做开始标签属性归一（h1–h6、details、summary、th、td、table、thead、tbody、tr、ul、ol、li、p、pre、code、figure、blockquote、mark），使 `<h1 id=…>` ≡ `<h1>`、`<details open>` ≡ `<details>`、`<th style=…>` ≡ `<th>`；属性类原文片段（`class=`、`id=`、`alt=` 等）仍按原文严格命中，纯文本片段不归一。
- `html_not_contains` 仅在 `<body>…</body>` 范围内检查，head 内的 `<style>`/`<title>` 不计为正文泄漏。
- 金样比较保持原文严格，不受上述归一影响。
- `no_overlap`：PDF 版面未暴露块级包围盒，改用 headless UI 的块几何（`top`/`height`，容差 0）判断相邻块不相交；该断言记在 PDF 表面。
- PDF 关键文本：PDF 字节流中文本为字形 CID，无法直接检索 Unicode；关键文本取自同一次 `layout_document` 的 `DrawOp::Text`（与 `render_pages` 同一版面数据）。
- PRINT：断言打印分页模型（页数/断点单调/首断点为 0）；物理打印需要 GDI 设备上下文，不在本矩阵断言口径内，真实打印样张见 `docs/qa/w10-output-pipeline-evidence.md`。
- HTML 中的 Mermaid：harness 经测试门面注入产品同一离线渲染器（`platform::mermaid_offline::OfflineMermaid`：进程内 QuickJS + mermaid.js → resvg，无网络；`OnceLock` 使整轮测试只初始化一次），`export::html_of_doc` 收到真实 `MermaidImage.svg_text`。断言要求正文出现 `<svg` 且不得同时保留 `language-mermaid` 源码围栏降级形态；单块渲染失败即判 FAIL，不降级断言。
- 空态用例（CASE-EDGE-001..003）：语料的 `表面：N/A` 只说明「无可见内容」，不等于不可测。harness 在六个表面执行空态断言：UI 0 块且几何有限、HTML `<body>` 为空、PDF 恰 1 页空白且无版面文本（依据 `layout_document` 无条件 `new_page()`、`LayoutOpts::default().page_numbers == false`）、PRINT 恰 1 页且断点为 `[0.0]`（依据 `compute_page_breaks` 恒以 `vec![0.0]` 起步）。
- Mermaid 用例不做全文金样：SVG 内的路径/弧坐标由 dagre 布局与字体度量共同决定，跨进程运行存在浮点级差异（classDiagram / stateDiagram 的 `d` 属性实测会变），全文金样必然 flaky；改由结构断言证伪「未渲染却算通过」：`<body>` 必须含真实 `<svg`，且不得残留 `language-mermaid` / 「渲染数据不可用」降级围栏。
- 容器内 Mermaid：列表/引用容器里的 ```mermaid 围栏按容器内容原样保留为代码块（`<pre><code class="language-mermaid">`），不提升为顶层 Mermaid 块、不自动出图；结构不丢失，限制登记为 G7。
- 金样首次缺失时自动写入（引导），之后普通运行全文比对。
