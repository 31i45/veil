## 关键结果

- 客户区 210×240 物理 = 140×160 逻辑（DPI 144）；窗口外框 232×296。
- 浮层卡片 `y=54..201`、`h=147`、`line_h=27`；行矩形
  `60..87 / 87..114 / 114..141 / 141..168 / 168..195`，全部 `< 201`（状态栏上沿）且 `< 240`。
- 截图可见首行`保存失败：拒绝`与末行`另存为`；中间行按“首末优先”策略让位，无半行裁切。
- 同目录 `n-140x160-notice/` 是 walkthrough 只能改宽的废弃预跑（高仍 1106），不作为结论。

### 2) 链接错误常驻

- Ctrl+点击 `[unsupported-link-target-abcdefgh](ftp://example.com)`。
- t0 与 t=7s 截图 SHA 完全相同（`26A1BF982C367D3FED0F4C184F1FD1BC5A62707B556CE75EAD946A4104060BF1`），
  证明错误通知不参与 6s TTL。
- 代码：链接拒绝走 `notify_error`（`interaction.rs:2876-2882`）；错误类不超时
  （`chrome/mod.rs:630-645`、`app.rs:1699-1716`）。

### 3) 打印/PDF 失败回执

- `NoticePrintFailed`：
  `打印失败：{}；可重试打印，或检查打印机是否联机、驱动是否正常后重试`（`i18n.rs:407-408`）。
- `NoticeExportPdfFailed`：
  `导出 PDF 失败：{}；可重试导出，或检查目标目录是否可写、文件是否被占用后重试`（`i18n.rs:412-413`）。
- `PrintNoPrinterContext`：
  `打印失败：无法获取打印机上下文；请检查打印机连接后重试，或改用导出 PDF`（`i18n.rs:419-420`）。
- 以上三类均为 Error 通知并常驻；测试
  `app_tests.rs:17496`、`17547`、`i18n.rs:883` 全部通过（`tests.txt`）。
- 未实拍原因：Windows 打印/另存对话框无法在不改系统打印机或不经用户选择的情况下稳定注入失败。
  人工复现：停用/离线默认打印机后 文件→打印…；或在 导出 PDF 对话框选只读目标目录后保存。
  不伪造失败截图。
