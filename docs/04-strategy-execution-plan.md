## 1. 战略命题

**战略身份选 B，质量门槛守 A 的核心子集。**

- **B（身份）**：做「最快、最可信、最懂中文长文」的 Markdown 编辑器，而不是「功能更多的 Typora」。
- **A（门槛）**：CommonMark 核心子集 + GFM 常用语法 + 数据安全必须达标；不追求 652 例 100%。
- **不做什么**：docx/ePub/LaTeX/MediaWiki、Mermaid、插件市场、云同步、AI 功能——除非用户数据证明必须。

产品一句话：

> 为中文长文与技术写作打造的、最快且永不背叛源码的 Markdown 编辑器。

## 2. 「一流」的五条硬标准

| # | 标准 | 当前判断 | 验证方式 |
|---|---|---|---|

| 5 | 有理由：一句话说清为什么选它 | 未证明 | 目标用户盲测 |

### 4.2 P3 鲁棒性冒烟

- 边界输入：0 字节、损坏 UTF-8、10MB 单行、10 万字中文、深嵌套 inline、超长列表/引用。
- 故障注入：保存途中杀进程、外部修改/删除、磁盘写入失败（用失败注入的 Store 测试）。
- 判定：不 panic、不挂起、不产生半截文件、可恢复。
- 本轮先做「短时冒烟」；长时 soak 留到 G1。

### 4.3 P4 专家启发式预审

按以下清单逐项打勾，记录阻断项：

1. 首屏是否在 3 秒内可输入，是否有空白/闪烁。
2. 打开 1 万字文档后，光标是否始终可见、滚动是否跟手。
3. 输入中文时，候选框是否跟随、组合期文本是否错位。
4. 光标进出粗体/链接/代码时，标记展开是否引起行高跳动。
5. 列表/引用/分隔线/代码块的视觉层级是否稳定。
6. 查找替换是否可见、可取消、计数正确。
7. 菜单/工具栏是否可键盘到达，Esc 是否能退出。
8. 外部修改、文件缺失是否有明确提示。
9. 表格与图片是否在真实文档中可读、可操作。
10. 崩溃/退出后是否有未保存内容丢失风险。

### 6.2 已落地：快速打开（Ctrl+P）+ 最近/目录候选（2026-10-29）

- **入口**：Ctrl+P 或文件菜单「快速打开…」。浮层期间文档只读（`Mode::QuickOpen`），

### 6.3 已落地：B7 源码标记显隐统一（2026-10-29）

### 6.4 已落地：图片粘贴/拖拽 + WIC 解码（2026-10-29）

- **粘贴**（切片 14，沿用）：剪贴板 HTML→Markdown → 纯文本 → 位图；位图落盘

- **拖拽**（本次）：`HoveredFile` 记录文件名，内容区压暗 + 居中提示条（图片「松开以插入

### 6.5a 附带修复：Memo 因果键的 Reveal 指纹（2026-10-29）

`memo_hit_equals_forced_after_any_sequence`（性质测试，100 例）长期失败，最小反例
`[Newline, MoveDocStart]`。两处根因均在 `view/layout.rs`：

1. 指纹输入 `node_ranges` 存的是**文档绝对坐标**；增量重解析保留 BlockId 但块 range 整体平移，
   命中校验用旧绝对区间与新 caret 比对 → 把块外 caret 误判为块内激活。
2. 未折叠标题（ATX/Setext）与围栏代码的**块级激活位**，其指纹恒为 FNV 初值 → caret 进出
   这些块时缓存永不失效，残留 `#`/围栏标记。

修法：指纹输入统一改存**块相对坐标**（含新增的行内图片区间），`reveal_state` 增加「caret 在
块外则一律不激活」守卫，并把块级激活位补齐到与 `block_subs` 判定面一致。回归由两条确定性
用例钉死（标题块、围栏块各一），`proptest-regressions/app_tests.txt` 保留失败种子入库。

### 6.5b 第二根因：增量重解析的「干净块」对齐（2026-10-30）

同一性质测试仍有偶发失败，最小反例显示 memo 命中 `"sn题"` 而强制重排得 `"sn标题"`——
同一 BlockId 的缓存布局是旧内容。根因不在视图层，而在内核
`syntax::Syntax::reparse`：判断「后缀遇到干净块、可提前停扫」时只比**起始行平移对齐 +
首个块种类**，未比**结束行**。块边界一变（内容已改，但首行与种类恰好对齐）就提前停扫，
其后的旧 BlockId 被整体平移复用，派生缓存按 id 命中陈旧布局。

修法：对齐条件补齐结束行平移比对；并把「先扫块再比对」作为实现形态——旧写法在比对时
再调一次 `scan_next`，对齐失败后会逐行重扫导致 O(n²)。回归：
`suffix_ids_preserved_across_block_kinds_after_edit`（列表/引用/围栏/表格后缀 id 全保留）、
`suffix_not_reused_when_block_boundary_changed`（边界变化必须换新 id）。
