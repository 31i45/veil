# Veil v1.2 Roadmap

目标窗口：**v1.1 收尾后约 4–6 周（无硬 deadline，按体积预算推进）**。
状态：v1.2-1（PDF 直接导出）与 v1.2-2（源码模式）已在 converge 批次交付；HTML 主题 CSS 导出、GFM 脚注与文档内锚点已在 v1.2 文档增强批次（2026-11-06，Unreleased）交付；v1.2「手感与表达」批次（2026-11-09）交付编辑手感、排版表达与信任可见项；候选池剩余排版设置、PDF 书签与字体子集化（表格合并/拆分与列宽拖动已撤销）。

---

## 永恒设计原则重申

**Veil 是单机单用户纯离线 Markdown 编辑器。永不引入多用户协作、网络同步、云端存储、任何形式的网络访问。**
本 roadmap 中所有条目均为单机单用户、可完全离线完成的场景；任何需要联网、账号或多端同步的方案一律不立项。

---

## 判定口径

| 用词 | 定义 |
|---|---|
| **标配** | 同类 Markdown 编辑器普遍具备、缺失会被用户直接感知为"不完整"的能力。 |
| **特色** | 同类产品少见或实现路径独特（如自研状态机、自绘 chrome），构成 Veil 差异化卖点的能力。 |
| **鸡肋** | 技术上可做、但使用频次低或收益被现有能力覆盖，投入产出比明显不划算的能力。 |
| **不值得** | 与单机单用户纯离线定位冲突，或需要新增外部运行时依赖 / 持续维护成本的能力。 |
| **证据债** | 功能已实现但缺少可复现的真机或自动化证据，需要补测、补录、补断言，而不是补代码。 |

## 能力基线（已具备，不再立项）

以下能力 v1.x 已实现并有测试或真机证据，仅作为候选池的去重基线，不重复立项：

- 查找替换
- 大纲面板
- 快速打开（Ctrl+Shift+P）
- 自动保存
- 崩溃恢复（recovery.dat）
- 外部修改提示与覆盖前备份
- 打印（Ctrl+P 系统打印对话框）
- 直接导出 PDF（`Ctrl+Shift+E` / 文件菜单；目录、页码、页边距可配置）
- 源码模式（`Ctrl+/`，全文源码视图）
- HTML 导出（Ctrl+E；内联 CSS 跟随当前浅/深主题）
- GFM 脚注（`[^id]` 引用/定义、`Ctrl+单击` 双向跳转、导出文末脚注列表）
- 文档内锚点跳转（`[文本](#slug)`、导出标题 `id`、重复标题去重）
- 链接用系统默认程序打开（`Ctrl+单击`、右键「在浏览器中打开」）
- 图片粘贴 / 拖拽插入
- 公式（latex-rust 纯 Rust 路径）
- 专注模式 / 打字机模式
- 链接主题色（浅 `#2B6CB0` / 深 `#7FB4F5`）
- 菜单键盘导航（↑/↓ 选择、Enter 执行、Esc 关闭）
- 表格行列增删与列对齐（右键菜单，一次 undo）
- 单元格富文本（非活动格渲染标记，活动格显示源码）
- 性能探针（`VEIL_PERF_PROBE=1` + `tools/walkthrough.ps1 -Perf`）
- 代码块语法高亮：16 种语言，自研逐行状态机，不引入 syntect
- CJK 排版：中英自动间距、行首行尾禁则、满行悬挂标点
- 自绘 chrome：菜单栏 / 状态栏 / 滚动条
- 行移动 `Alt+↑/↓`（单 undo，多行选区）
- 翻页 `PageUp/PageDown`（光标同步）与按词删除 `Ctrl+Backspace`/`Ctrl+Delete`
- 查找「区分大小写」（默认关）与 `Enter`/`Ctrl+Enter` 替换
- 光标焦点表达（实心/空心，零定时器）
- 可读列宽上限、H4=H5=H6 字阶与标题段距
- 状态栏保存态（「已保存 · HH:MM」/「未保存」）与 CLI 打开失败可见

## 明确不做

| 条目 | 判定 | 理由 |
|---|---|---|
| Mermaid 全量渲染 | 不值得 | 渲染引擎体积与维护成本远超预算；最多降级为只读代码块展示 |
| 插件系统 | 不值得 | 破坏单文件 exe 与确定性行为，且需要稳定的外部 API 契约 |
| 多标签 / 多文档 | 不值得 | 与"单文档定位"冲突，会牵动文档模型、崩溃恢复与外部监听的全部假设 |
| 拼写检查 | 鸡肋 | 需内置词典与语言模型，体积代价高；系统输入法已覆盖大部分场景 |
| 安装器 / 文件关联注册 | 不值得 | 便携单文件是核心卖点，安装器会引入写注册表与卸载链路 |
| 自动更新与遥测 | 不值得 | 违反纯离线原则，任何网络访问均属违规 |
| 正则查找 / 全词匹配 | 不值得 | 正则引擎净增 1,198,592 B（且 `lapce-xi-rope` 硬依赖默认特性无法瘦身），表达力仍不完整；`\b` 对 CJK 无语义，「全词」≈「全串」 |
| 自动配对 | 鸡肋 | 净收益 ≈ 0 个本质动作；需 5 条规则 × 4 组排除面，并引入新配置键 |
| `Ctrl+Shift+K` 删除行 | 鸡肋 | 删除行已有选中行 Delete / `Ctrl+X` 两条零成本路径；与既有 `Ctrl+K`（插入链接）相邻，误触丢行 |
| 状态过渡 / 缓动 | 不值得 | 与「击键优先、零空闲开销」冲突；过渡只推迟结果可见，属装饰性动效 |
| H5 / H6 独立字阶 | 鸡肋 | 真实文档 H5/H6 出现率 <1%；六档挤在窄区间，最小档差肉眼不可辨（本轮 H4=H5=H6，靠缩进/字重区分） |
| 列表悬挂缩进 | 不值得 | 换行引擎无行级缩进原语；需逐行插空格改写排版流，破坏 doc↔layout 偏移致密映射 |
| 设置 UI | 鸡肋 | 配置键仍 <20，`config.toml` 足够；UI 引入表单状态机与 100–200 KB 体积 |
| YAML Front Matter 专属渲染 | 不值得 | 需 YAML 解析与元数据卡片状态机，破坏「纯文本往返」；至多允许视觉只读实现 |
| 内核 DOCX / ODT / LaTeX / ePub 导出 | 不值得 | 每种是一套排版模型，与 Markdown 往返冲突并把单文件推向 10 MiB+；只允许外部转换器接缝 |

## 体积预算门禁

- 上限：**6 MiB = 6,291,456 B**（不因任何新功能上调）。
- 本轮基线（2026-11-09 Task 0.1 实测）：release exe **6,026,240 B**，余量 **265,216 B**。
- 本轮交付后实测：release exe **6,043,136 B**（≈ 5.76 MiB），余量 **248,320 B**，仍低于门禁。
- 测量命令：`(Get-Item target\release\veil.exe).Length`；构建：`cargo build --release -p veil`。
- 任何条目若预估使 exe 超限，必须降级或否决，不得先合入再优化。
- 禁止新增外部运行时依赖（无 webview、无 Chromium、无可选运行时），依赖黑名单沿用 `tokio`、`wasmtime`、`webview2-com`/`wry` 等。
- 每个条目合入前需给出 release 构建实测体积，并与本条目的预估区间对照记录。
